# MAHIRA SELECT — Luxury Indian Haute Couture & Artisanal Heritage Website

A pixel-perfect, hyper-elevated recreation of the **Mahira Select** interactive luxury website from Gireesh's showcase video (`@itsgireesh.uiux`).

---

## ✨ Features Included (ভিডিওর হুবহু ও আরও উন্নত ফিচারসমূহ)

1. **Royal Satin Curtain Reveal (রয়্যাল সাটিন কার্টেন রিভিল)**
   - 3D pleated velvet/satin drape in royal wine crimson with realistic specular fold highlights.
   - Gold Filigree Crest Monogram & Typography.
   - Smooth cinematic parting animation revealing the underlying experience.
   - Floating **"Curtain View"** button to re-draw the curtain anytime.

2. **Indian Classical Audio Atmosphere Engine (ওয়েব অডিও অ্যাম্বিয়েন্স)**
   - Synthesizes authentic Indian sitar drone and meditative Tanpura harmonics using the browser's native **Web Audio API** (100% offline, zero external audio dependency!).
   - Hero audio widget with interactive play/pause, live audio frequency waveform visualizer on HTML5 Canvas, and volume slider.

3. **Aristocratic Navigation & Mega Menu (লাক্সারি মেগা-মেনু)**
   - Hovering over **"Kalakaari"** unveils a multi-column artisanal directory (Sarees, Dress Sets, Fabric, Dupattas + Featured Collection preview card).
   - Live Search drawer, Wishlist toggle with toast notifications, and Shopping Bag counter.

4. **Hero Section ("More Than Fashion")**
   - Tagline: *"Tradition Meets Tomorrow"*
   - Display Typography: *"More Than Fashion — A story in every drape."*
   - High-fashion model portrait in embroidered bridal couture saree.
   - Floating brass urli bowl badge with Varanasi GI-tagged silk mark certification.
   - Right-edge vertical tag: *"HIGH TASTE DESIGN FOR TOMORROW"*.

5. **Transition Statement Marquee**
   - Infinite sliding luxury text ticker: *"New Collections For Women — From silhouettes. Timeless craftsmanship. Made for you."*

6. **Dual Featured Category Split Cards**
   - **WOMEN**: *"Elegance in every drape, for every you."*
   - **KALAMKARI**: *"Art that tells a story."*

7. **Interactive Artisanal Accordion Gallery ("Rooted in Indian Artistry")**
   - Horizontal accordion with smooth flex expansion on hover/click:
     1. Kalamkari Sarees
     2. Kalamkari Fabric
     3. Kurta Sets
     4. Artisanal Dupattas
   - Automatically adapts into a touch-optimized vertical stack on mobile!

8. **Bento Grid Best Sellers Showcase**
   - Live category filtering: *All*, *Sarees*, *Kurta Sets*, *Kalakaari*, *Dupattas*.
   - Dual-image hover angle flips, quick add to bag, and price formatting in INR (`₹`).

9. **Interactive Slide-Over Shopping Bag (কার্ট ড্রয়ার)**
   - Real-time cart state with `localStorage` persistence.
   - Quantity modifiers (`+` / `−`), item removal.
   - Free shipping progress threshold tracker (Orders above ₹15,000).
   - Privilege voucher system (Try code: `MAHIRA10` for 10% discount).

10. **Quick View Modal**
    - High-resolution multi-view gallery, silk composition details, size and draping selector, and direct checkout.

11. **100% Mobile Responsive (মোবাইল ও ট্যাবলেট অপ্টিমাইজড)**
    - Designed specifically to match the DevTools iPhone 14 Pro Max view shown in the video!

## 🚀 How to Run (কীভাবে চালাবেন)

### অপশন ১: সরাসরি ব্রাউজারে ওপেন করুন (No installation needed!)
- `index.html` ফাইলটিতে ডাবল ক্লিক করুন বা যেকোনো ব্রাউজারে (Chrome, Safari, Edge) ওপেন করুন।

### অপশন ২: লোকাল সার্ভার দিয়ে চালানো
যেকোনো সাধারণ লোকাল সার্ভার কমান্ড চালাতে পারেন:

```bash
# Python দিয়ে:
python3 -m http.server 5173

# অথবা npx দিয়ে:
npx serve .
```
এরপর ব্রাউজারে `http://localhost:5173` ওপেন করুন!
